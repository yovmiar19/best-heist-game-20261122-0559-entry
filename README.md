Build a complete, original heist game that plays offline in a desktop browser from its own files; an AI judge compares the games two at a time, places go by win rate, and the 10 best share $50.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Velvet Vault, a one-room stealth heist: sneak past guards and cameras, crack the vault, grab the Star Sapphire and escape before the alarm hits 100.
